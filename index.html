The QuarkCreation

A QuarkForce character roadmap

How to take a character from a loose thought to finished artwork, a commercial, merchandise, a website and a promotion plan. Seven steps, one folder.

LET'S BUILD
📁

Before anything else: make a folder where all the art, audio and video goes. Everything you create from here on lives in it.

01

Create the Character!

  • Get inspired by life and any other random thought or person.
  • Do a loose draw in pencil, on paper or in Procreate.
  • Gather references for character construction: arm and leg positions, etc.
  • Gather references for character accessories: bags, gloves, weapons, etc.
  • Scan to your computer if needed.
  • Tighten and finalize the drawing: final line work, shading, highlights and rendering.
  • Name the character. It now has life and energy to begin its journey!
  • Make them a custom name logo that lives with them.
  • Name the folder after your character, and make sure everything you've created so far is in it.
EXAMPLE: GRAFFITI GRANNY

Graffiti Granny was created from a painting class I taught. I once had an older woman as a client. Her doctor told her she should learn how to paint and take a painting class, and she came to me. When I explained to my friends that I was teaching an older woman how to paint, they jokingly asked if I was teaching her graffiti. I found it very amusing and created this character!

02

Bring the Character to Life!

  • Determine the character's "role" in the QuarkForce Universe.
FOR EXAMPLE

"Marvelous Wonderful would be perfect for X."

"Alagbarawo Shrunken turned out to be the perfect mascot for my CanvasWars art battle event." Some sort of bigger mission they can be a part of whenever they arise.

  • This is where we begin to integrate digital tools.
  • Run your character through your favorite AI image generator with the prompt Ultra Realistic (or any similar variation, or a style of your choice). Regenerate and edit the prompt until you get the realistic version of your character that works best.
  • (Optional) Run the character's name logo through your favorite AI image generator with a prompt like: biker jacket patch logo Or any logo reveal style that fits your character.

2.5 — Video Time!

  • Run your character through your favorite AI video generator at the appropriate aspect ratio, with a prompt like: make a commercial for "Gloria BirdMoney Luxury Jewelry" Or any animation, prompt and style that fits your character. Collect about 2–3 good clips to use. (I use the free version of Flow by Google, with 10-second scene clips. Planning to upgrade to the paid version of Krea soon.)
  • Run the character's name logo through your favorite AI video generator with a prompt like: gold and diamonds luxury jewelry logo reveal Or any logo reveal style that fits your character and logo. (I use Flow with a 6-second clip.) We'll use it as the intro and outro of the video.
  • Save everything in your character folder.

+ Option B

If the original prompt rendering didn't quite do what you'd like:

  • Use your favorite AI to write you a script for your new character, or one that introduces the character.
  • Use the ElevenLabs voice AI generator. Find the voice tone and style that best fits, run the script you got, then generate and download.
  • Use Suno to find a "score" or instrumental you can use for the whole commercial.

03

Video Editing

I use Filmora to edit my video clips. There are many different video editing programs out there, so use your favorite.

  • Bring all the video clips you'd like to use into your video editing software.
  • Bring all the audio you'd like to use into the software.
  • Insert the logo reveal intro.
  • Add scene 1 and scene 2.
  • Add the ElevenLabs audio to the scenes, if you're using it on the project.
  • Add the outro logo reveal.
  • Add the instrumental or "score" to the video project.
  • Render the project.
  • Export.

05

Website

At this point you hopefully know your character pretty well. Ask yourself: "If this character had a business, what would it be?" or "X would be the perfect character for this."

EXAMPLE: ROBINBILLIONS

One of my characters, RobinBillions, is a sneaky thief. He has a big gold safe on his back and a cash register in his hand, and he's stepping over an alarm signal. I made his business a 24-hour moving service, then made a logo, a commercial and a webpage around that business.

Build the page

  • Use your favorite AI to generate a Claude HTML prompt. My steps: upload and describe your character and the business they would most realistically run. For example: make me a Claude prompt for a fully functional HTML website for "Angel Thump Babysitter Service"
  • Run the prompt through Claude and download the HTML code.
  • Once the HTML is downloaded, it must be named index.html to work in GitHub.

Host it on GitHub

GitHub is the server I use to run the HTML code I receive from Claude.

  1. In GitHub, click the + button to make a new repository.
  2. Add a name and description, then save.
  3. Upload your existing HTML code.
  4. Go to the Settings tab, then the Pages section. Change the branch from None to Main and save.
  5. Make sure the file is titled index.html. If needed, you can rename it by clicking the pencil icon.
  • Once the site is fully active, you can adjust and edit as needed. I use Gemini to help with all my small technical adjustments once the HTML is up and running, via screenshots and so on.
  • Finally, I got my domains from IONOS (JawsGraffiti.com and canvassers.org) and was able to set them up to point directly to the GitHub sites easily.
